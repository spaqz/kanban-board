# Kanban Board (Аналог Jira)

Полноценное клиент-серверное приложение Kanban-доски, разработанное в рамках лабораторной работы по дисциплине "Поддержка и тестирование программных модулей".

## 🚀 Стек технологий
* **Backend:** Node.js, TypeScript, Express, Prisma ORM
* **База данных:** SQLite (для простоты развертывания, без Docker)
* **Тестирование:** Jest, Supertest
* **Документация API:** Swagger UI
* **Аутентификация:** JWT (JSON Web Tokens), bcrypt

## 📋 Реализованный функционал
* Регистрация и авторизация пользователей (JWT).
* Роли: ADMIN, MANAGER, DEVELOPER.
* Создание, редактирование и удаление проектов.
* Создание досок (автоматическое создание 3 колонок: To Do, In Progress, Done).
* Управление колонками (WIP-лимиты).
* Управление карточками (создание, перемещение между колонками, назначение исполнителя).
* История действий (Activity).
