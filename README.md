# 🐗 Канбано (Kanbano) — Канбан-доска для управления задачами

Fullstack-веб-приложение, разработанное в рамках учебного проекта. Представляет собой полноценную Канбан-доску с регистрацией пользователей, сохранением задач в реляционной базе данных, REST API и настроенным CI/CD.

## 👥 Команда проекта
* **Frontend-разработчик:** [Твоё Имя] — разработка пользовательского интерфейса (HTML/CSS), клиентская логика (Vanilla JS), интеграция с API, работа с JWT.
* **Backend-разработчик:** [Имя Маши] — проектирование базы данных, написание REST API (TypeScript/Express), настройка ORM Prisma, покрытие кода тестами.

## 🛠 Стек технологий

**Frontend (Клиентская часть):**
* HTML5, CSS3 (Flexbox, Grid, адаптивная верстка)
* Vanilla JavaScript (ES6+)
* Fetch API для взаимодействия с сервером
* JWT (JSON Web Tokens) для авторизации

**Backend (Серверная часть):**
* Node.js + TypeScript
* Express.js (веб-фреймворк)
* Prisma ORM (работа с базой данных)
* SQLite (реляционная база данных, хранится в файле)
* Bcrypt (хеширование паролей)
* Swagger (автогенерация документации API)

**Тестирование и CI/CD:**
* Jest + Supertest (интеграционные тесты)
* GitHub Actions (автоматический запуск тестов при пуше)

---

## ✨ Основной функционал
* **Авторизация:** Регистрация и вход по Email и паролю (с валидацией и шифрованием).
* **Доска задач:** Создание и удаление колонок (списков).
* **Карточки:** Добавление задач с указанием названия и дедлайна.
* **Статус задач:** Возможность отметить задачу выполненной (зачеркивание).
* **Профиль:** Просмотр и редактирование личных данных пользователя.
* **Страница процессов:** Сводный список всех активных задач с указанием колонок.
